# AI Text Summarizer

AI-powered text summarization web app using Flask, React, and the T5 transformer model. Converts long text into concise summaries with real-time processing and an interactive UI.

## Tech Stack
- Flask (Backend)
- React (Frontend)
- T5 Transformer (NLP)
- MySQL

## Features
- Real-time text summarization
- Full-stack architecture
- REST API integration
- Responsive UI

## How to Run
1. Start backend: `python server.py`
2. Start frontend: `npm start`
